## 🚀 What is Vibe Voyage?

**Vibe Voyage** is an AI-powered travel recommendation system that matches *your emotion* to real-world places.

Instead of searching:

> “Best places in Puri”

You search:

> “I feel peaceful and reflective.”

And the system understands your vibe — then suggests places that emotionally match it.

---

## ✨ Core Highlights

| Feature | What It Does |
|----------|--------------|
| 🎭 Mood Input | User enters emotion instead of keywords |
| 🧠 RAG Ranking | Semantic similarity using embeddings |
| 📍 Google Maps Integration | Live map + real place markers |
| ⭐ Feedback Learning | System improves from user ratings |
| 💙 Wishlist Passport | Save & revisit favorite places |

---

## 🧠 How It Works (AI Flow)
**User Mood Input** → **Emotion Mapping Layer** → **Google Places API Fetch** → **RAG Semantic Re-ranking** → **Feedback-weighted Adaptive Ranking** → **Personalized Recommendations**
